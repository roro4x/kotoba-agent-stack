# Kotoba Lesson

Провести один завершённый урок в пределах выбранной длительности. Считать локальные файлы состояния источником истины между сессиями.

## Подготовка

1. Прочитать `learner/profile.json`, `learner/settings.json` и `learner/mastery.json`. Если выбран Python-режим, вместо этого можно запустить `python3 tools/kotoba_state.py summary --json`.
2. Если профиль отсутствует, остановиться и предложить `$kotoba-settings`.
3. Прочитать [lesson-policy.md](references/lesson-policy.md), `docs/state-format.md` и `curriculum/catalog.json`.
4. Выбирать сначала элементы со статусом `learning` или низкими результатами, затем зависимости следующей новой темы.
5. Не включать элементы `reported_known` в объяснение. Допустимо дать один короткий контрольный вопрос.

## Структура урока

1. Обозначить цель урока одной фразой.
2. Дать короткое разогревающее повторение без подсказок.
3. Ввести одну грамматическую конструкцию и 5–10 связанных слов; уменьшать объём для коротких уроков.
4. Показать 2–4 естественных примера с переводом. Следовать настройке фуриганы.
5. Провести управляемую практику, затем самостоятельное задание.
6. Проверять ответ, объяснять конкретную ошибку и дать одну попытку исправления.
7. Завершить кратким итогом и записать результаты через `record`.

Если ученик сообщает, что тема или слово уже известно, сразу вызвать `mark-known`, удалить его из объяснения и заполнить освободившееся время практикой или следующим зависимым элементом.

## Различия целей

- `jlpt`: уделять больше внимания распознаванию форм, частицам, чтению, типовым ловушкам и ограниченным по времени заданиям.
- `conversation`: уделять больше внимания порождению реплик, вариантам вежливости, реакции без перевода и коротким ролевым диалогам.
- Для обеих целей сохранять базовую грамматику, лексику, чтение и понимание на слух; менять акцент, а не полностью исключать направления.

## Сохранение урока

Сохранить структурированную запись в `lessons/YYYY-MM-DD-NNN.json` по [lesson-schema.md](references/lesson-schema.md). Затем записать оценки элементов по `docs/state-format.md` файловыми инструментами агента.

В опциональном Python-режиме использовать:

```bash
python3 tools/kotoba_state.py record grammar.topic-wa --score 0.75 --mode production --lesson lessons/2026-08-19-001.json
```

Использовать значения от `0` до `1`. Не ставить `1` только за прочтение объяснения.

## Ограничения

- Не придумывать завершённые уроки или результаты, которых не было.
- Не перегружать урок длинной лекцией.
- Не вводить новую грамматику без необходимых зависимостей.
- Не считать один удачный ответ устойчивым освоением.
