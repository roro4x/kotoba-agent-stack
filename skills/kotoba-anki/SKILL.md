# Kotoba Anki

Все сообщения, preview и предупреждения давать по-русски; японский использовать в содержимом карточек. Менять язык интерфейса только по явной просьбе ученика. Работать с Anki только после явного согласия пользователя. Использовать гибридную организацию: `Kotoba::NNN — Название` и тематические теги.

## Предварительный просмотр

1. Проверить `learner/settings.json`: `anki.enabled` должно быть `true`. Иначе предложить `$kotoba-settings`.
2. Прочитать [anki-policy.md](references/anki-policy.md).
3. Проверить обязательные поля JSON урока по [anki-policy.md](references/anki-policy.md) файловыми инструментами агента.
4. Сформировать и показать preview: имя подколоды, поля карточек, создаваемые стабильные ID и теги. Не применять изменения автоматически.

Если выбран Python-режим, preview можно получить командой:

```bash
python3 tools/kotoba_anki.py lessons/2026-08-19-001.json
```

## Синхронизация

Автоматическая синхронизация требует либо поставляемого Python-адаптера, либо явно доступного совместимого Anki MCP. Без одного из них сохранить preview и объяснить, что карточки ещё не отправлены в Anki.

Для Python-адаптера убедиться, что Anki открыт и AnkiConnect доступен на `http://127.0.0.1:8765`. После подтверждения пользователя выполнить:

```bash
python3 tools/kotoba_anki.py lessons/2026-08-19-001.json --apply
```

Инструмент имеет право изменять только заметки с тегами `kotoba-managed` и `kotoba-id-*`. Не удалять заметки и колоды.

## Прогресс Anki

Для чтения статистики через поставляемый Python-адаптер выполнить:

```bash
python3 tools/kotoba_anki.py --stats
```

Использовать частые ответы Again, lapses и короткие интервалы как сигнал для повторения, но не заменять ими результаты активной речи и грамматики. Не менять расписание Anki.

## Отказоустойчивость

- При недоступном AnkiConnect сохранить только предварительный просмотр.
- Не требовать Python, если пользователь хочет только preview или ручное добавление карточек.
- Не утверждать, что синхронизация или чтение статистики выполнены, если доступен только файловый режим.
- При неоднозначном совпадении не обновлять заметку и сообщить об этом.
- Перед массовым применением рекомендовать синхронизацию или резервную копию Anki.
