# Kotoba Anki

Работать с Anki только после явного согласия пользователя. Использовать гибридную организацию: `Kotoba::NNN — Название` и тематические теги.

## Предварительный просмотр

1. Проверить `learner/settings.json`: `anki.enabled` должно быть `true`. Иначе предложить `$kotoba-settings`.
2. Прочитать [anki-policy.md](references/anki-policy.md).
3. Проверить JSON урока без подключения к Anki:

```bash
python3 tools/kotoba_anki.py lessons/2026-08-19-001.json
```

4. Показать создаваемые и обновляемые карточки. Не применять изменения автоматически.

## Синхронизация

Убедиться, что Anki открыт и AnkiConnect доступен на `http://127.0.0.1:8765`. После подтверждения пользователя выполнить:

```bash
python3 tools/kotoba_anki.py lessons/2026-08-19-001.json --apply
```

Инструмент имеет право изменять только заметки с тегами `kotoba-managed` и `kotoba-id-*`. Не удалять заметки и колоды.

## Прогресс Anki

Для чтения статистики выполнить:

```bash
python3 tools/kotoba_anki.py --stats
```

Использовать частые ответы Again, lapses и короткие интервалы как сигнал для повторения, но не заменять ими результаты активной речи и грамматики. Не менять расписание Anki.

## Отказоустойчивость

- При недоступном AnkiConnect сохранить только предварительный просмотр.
- При неоднозначном совпадении не обновлять заметку и сообщить об этом.
- Перед массовым применением рекомендовать синхронизацию или резервную копию Anki.
