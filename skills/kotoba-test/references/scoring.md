# Оценивание

- `1.0` — точный самостоятельный ответ без подсказки.
- `0.75` — правильный ответ с небольшой оговоркой, не меняющей смысл.
- `0.5` — ответ после небольшой подсказки или частично правильный.
- `0.25` — узнавание после вариантов, но невозможность воспроизвести.
- `0.0` — неверный ответ или отсутствие ответа.

Для чтения отдельно учитывать чтение и значение. Опечатку в русском переводе не считать ошибкой знания. Для грамматики не снижать балл за лексику, если проверяется только конструкция и смысл остаётся ясным.
