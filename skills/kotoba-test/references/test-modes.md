# Режимы теста

| Режим | Вопрос | Проверяется |
|---|---|---|
| `meaning` | японское слово | значение |
| `reading-with-furigana` | слово и чтение | значение/употребление |
| `reading-no-furigana` | только кандзи | чтение и значение |
| `production` | смысл или ситуация по-русски | активное воспроизведение |
| `grammar` | фраза, пропуск или ситуация | форма и функция конструкции |

Для адаптивного теста использовать примерно 40% слабых, 40% текущих и 20% заявленных известными элементов. Не тестировать один элемент более двух раз за сессию.
