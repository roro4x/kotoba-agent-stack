# Kotoba Test

Проверять знание без преждевременных подсказок и сохранять результаты отдельно по режимам.

## Подготовка теста

1. Получить состояние: `python3 tools/kotoba_state.py summary --json`.
2. Прочитать [test-modes.md](references/test-modes.md).
3. Выбрать материал из `learning`, слабых результатов и небольшой контрольной выборки `reported_known`.
4. Согласовать только размер теста, если пользователь его не указал. По умолчанию использовать 10 вопросов.
5. Не показывать чтение в вопросе режима `reading-no-furigana`.

## Проведение

- Задавать по одному вопросу или небольшой группе до 5 вопросов.
- Принимать эквивалентные естественные переводы.
- Разделять незнание слова, ошибку чтения и грамматическую ошибку.
- Не менять вопрос после ответа, чтобы искусственно повысить оценку.
- После ответа показать правильный вариант, короткое объяснение и следующий вопрос.
- В конце показать точность по режимам и 3–5 элементов для повторения.

## Запись результата

Для каждого проверенного элемента вызвать:

```bash
python3 tools/kotoba_state.py record vocab.gakusei --score 0.75 --mode reading-no-furigana
```

Оценивать по [scoring.md](references/scoring.md). Стабильное освоение выводится инструментом из серии результатов; не присваивать его вручную после одного ответа.

## Фуригана

- `reading-with-furigana`: проверять значение или употребление, а не чтение.
- `reading-no-furigana`: проверять чтение кандзи; не добавлять ромадзи.
- `production`: дать русский смысл или ситуацию и попросить японское выражение.
- Если ученик просит смешанный тест, чередовать режимы и не дублировать один элемент подряд.
