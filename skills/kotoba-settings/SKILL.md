# Kotoba Settings

Настроить обучение и сохранить решения в локальном состоянии проекта. Общаться с учеником по-русски, если он не выбрал другой язык.

## Первый запуск

1. Проверить наличие `learner/profile.json`. Если файла нет, спросить имя или псевдоним, цель (`jlpt` или `conversation`), длительность урока и желаемый режим фуриганы.
2. Не проверять всю кану: считать, что ученик уже знает хирагану и катакану. Предложить короткую проверку только при сомнениях ученика.
3. Попросить свободным списком назвать уже известные грамматические конструкции. Не требовать формальных идентификаторов.
4. Провести адаптивную диагностику по [diagnostic.md](references/diagnostic.md). Задавать вопросы небольшими порциями и не показывать ответы заранее.
5. Создать профиль командой:

```bash
python3 tools/kotoba_state.py init --name "ИМЯ" --goal jlpt --minutes 25 --furigana adaptive
```

6. Отметить подтверждённые знания командой `mark-known`. Самооценку сохранять как `reported_known`, а доказанный тестом навык — как `mastered`.

## Изменение настроек

Использовать одну команду, передавая только изменяемые параметры:

```bash
python3 tools/kotoba_state.py configure --goal conversation --minutes 40 --furigana learning --anki true
```

Допустимые режимы фуриганы:

- `always` — показывать над всеми кандзи;
- `learning` — показывать для новых и слабых слов;
- `adaptive` — постепенно убирать после успешных ответов;
- `never` — не показывать, кроме явной просьбы.

## Уже известный материал

Если ученик говорит «я это знаю», уточнить только идентичность элемента, если она неоднозначна. Не заставлять проходить объяснение повторно. Записать один или несколько идентификаторов:

```bash
python3 tools/kotoba_state.py mark-known grammar.topic-wa vocab.gakusei
```

Предлагать короткую проверку, но позволять пропустить её. При ошибках позднее возвращать элемент в повторение на основании новых результатов.

## Ограничения

- Не менять файлы профиля вручную, если доступна `tools/kotoba_state.py`.
- Не включать Anki без явного выбора пользователя.
- Не выдавать самооценку за проверенное владение.
- После изменений показать краткую сводку командой `python3 tools/kotoba_state.py summary`.
