# Kotoba Settings

Настроить обучение и сохранить решения в локальном состоянии проекта. С первого ответа все вопросы, объяснения, исправления и сводки давать по-русски. Японский использовать внутри учебного материала. Менять язык интерфейса только по явной просьбе ученика.

## Выбор режима

По умолчанию работать без Python: прочитать `docs/state-format.md` и изменять JSON/JSONL файловыми инструментами агента. Если пользователь явно выбрал расширенный режим и Python 3 доступен, разрешено использовать `tools/kotoba_state.py`. Формат результата должен быть одинаковым.

## Первый запуск

1. Проверить наличие `learner/profile.json`. Если файла нет, спросить имя или псевдоним, цель (`jlpt` или `conversation`), длительность урока и желаемый режим фуриганы.
2. Не проверять всю кану: считать, что ученик уже знает хирагану и катакану. Предложить короткую проверку только при сомнениях ученика.
3. Попросить свободным списком назвать уже известные грамматические конструкции. Не требовать формальных идентификаторов.
4. Провести адаптивную диагностику по [diagnostic.md](references/diagnostic.md). Задавать вопросы небольшими порциями и не показывать ответы заранее.
5. Создать `learner/profile.json`, `settings.json`, `mastery.json` и `events.jsonl` по `docs/state-format.md`.
6. Отметить подтверждённые знания. Самооценку сохранять как `reported_known`, а доказанный тестом навык — как результат проверки.

В опциональном Python-режиме шаги 5–6 можно выполнить командами:

```bash
python3 tools/kotoba_state.py init --name "ИМЯ" --goal jlpt --minutes 25 --furigana adaptive
python3 tools/kotoba_state.py mark-known grammar.topic-wa vocab.gakusei
```

## Изменение настроек

В режиме без Python изменить только выбранные поля по `docs/state-format.md`. В Python-режиме использовать одну команду, передавая только изменяемые параметры:

```bash
python3 tools/kotoba_state.py configure --goal conversation --minutes 40 --furigana learning --anki true
```

Допустимые режимы фуриганы:

- `always` — показывать над всеми кандзи;
- `learning` — показывать для новых и слабых слов;
- `adaptive` — постепенно убирать после успешных ответов;
- `never` — не показывать, кроме явной просьбы.

## Уже известный материал

Если ученик говорит «я это знаю», уточнить только идентичность элемента, если она неоднозначна. Не заставлять проходить объяснение повторно. В режиме без Python записать `reported_known` по `docs/state-format.md`. В Python-режиме передать один или несколько идентификаторов:

```bash
python3 tools/kotoba_state.py mark-known grammar.topic-wa vocab.gakusei
```

Предлагать короткую проверку, но позволять пропустить её. При ошибках позднее возвращать элемент в повторение на основании новых результатов.

## Ограничения

- Не требовать установку Python для основного учебного цикла.
- Не смешивать два способа записи в одной операции.
- Не включать Anki без явного выбора пользователя.
- Не выдавать самооценку за проверенное владение.
- После изменений перечитать профиль, настройки и прогресс и показать краткую сводку. В Python-режиме можно использовать `python3 tools/kotoba_state.py summary`.
