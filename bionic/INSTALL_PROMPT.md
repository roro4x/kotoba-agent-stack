# Prompt установки Kotoba в Bionic

После открытия репозитория как Code Project вставить в Bionic следующий prompt:

```text
Отвечай только по-русски, начиная с первого сообщения. Ты выполняешь установочную проверку готового проекта, а не разрабатываешь его. Работай из корня открытого проекта. Не читай AGENTS.md и не создавай профиль ученика. Сам запусти через терминал `python3 tools/kotoba_bionic.py setup --run-tests`: не проси меня запускать, копировать или вставлять эту либо другую команду. Не создавай Python- или shell-скрипты и не редактируй проект. Если проверка успешна, сообщи мне по-русски одним коротким сообщением только абсолютный путь к `bionic/kotoba`, который нужно выбрать в настройке установки скилла Bionic. Если запуск заблокирован разрешениями, сам запроси доступ к терминалу; если Python отсутствует, кратко сообщи об этом и остановись. Не устанавливай пакеты, не запускай LM Studio и не изменяй learner/*.json. После установки этого скилла дальнейшие чаты должны использовать только kotoba и русский язык интерфейса, пока я прямо не попрошу сменить язык.
```

Установка каталога скилла через интерфейс Bionic остаётся единственным ручным шагом.
