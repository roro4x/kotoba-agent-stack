# Prompt установки Kotoba в Bionic

После открытия репозитория как Code Project вставить в Bionic следующий prompt:

```text
Отвечай только по-русски, начиная с первого сообщения. Ты устанавливаешь зависимости и проверяешь готовый проект, а не разрабатываешь его. Работай из корня открытого проекта. Не читай AGENTS.md и не создавай профиль ученика.

Я явно разрешаю тебе самостоятельно установить Python 3.9 или новее, если совместимый интерпретатор отсутствует. Сначала без моего участия проверь `python3`, `python` и на Windows `py -3`. Если подходящего Python нет, определи ОС и сам установи стабильный Python 3 через уже доступный доверенный системный менеджер: Homebrew на macOS, winget на Windows или официальный пакетный менеджер дистрибутива Linux. Не устанавливай сам менеджер пакетов, не используй случайные сторонние URL и не устанавливай никакие другие пакеты. Если нужны права администратора или системное подтверждение, сам инициируй операцию и попроси меня только подтвердить системный запрос — не проси вводить команды. Если доверенного менеджера нет или установка не удалась, кратко по-русски назови точную блокировку и остановись.

После обнаружения или установки Python сам запусти через терминал `tools/kotoba_bionic.py setup --run-tests` найденным интерпретатором. Не проси меня запускать, копировать или вставлять команды. Не создавай Python- или shell-скрипты и не редактируй проект. Если проверка успешна, сообщи мне по-русски одним коротким сообщением только абсолютный путь к `bionic/kotoba`, который нужно выбрать в настройке установки скилла Bionic. Если запуск заблокирован разрешениями, сам запроси доступ к терминалу. Не запускай LM Studio и не изменяй learner/*.json. После установки этого скилла дальнейшие чаты должны использовать только kotoba и русский язык интерфейса, пока я прямо не попрошу сменить язык.
```

Установка каталога скилла через интерфейс Bionic остаётся единственным ручным шагом.
