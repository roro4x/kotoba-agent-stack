# Prompt установки Kotoba в Bionic

После открытия репозитория как Code Project вставить в Bionic следующий prompt:

```text
Работай из корня открытого проекта. Не читай AGENTS.md и не создавай профиль ученика. Выполни `python3 tools/kotoba_bionic.py setup --run-tests`. Если проверка успешна, сообщи мне одним коротким сообщением абсолютный путь к `bionic/kotoba`, который нужно выбрать в настройке установки скилла Bionic. Если команда недоступна, сообщи только недостающее разрешение или Python и остановись. Не устанавливай пакеты, не запускай LM Studio и не изменяй learner/*.json. После установки этого скилла дальнейшие чаты должны использовать только kotoba.
```

Установка каталога скилла через интерфейс Bionic остаётся единственным ручным шагом.
