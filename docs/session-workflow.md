# Компактные чаты и checkpoint

Для чатов Bionic с контекстом до 32k не нужно загружать полный журнал событий, весь `mastery.json` и весь каталог. Facade `tools/kotoba_bionic.py` скрывает операции состояния, а `tools/kotoba_session.py` формирует компактный кэш `learner/context.json`.

## Начало чата

```bash
python3 tools/kotoba_bionic.py begin
```

Команда выводит:

- имя и настройки ученика;
- количество элементов по статусам;
- до 12 слабых или заявленных известными элементов;
- до 8 доступных кандидатов следующего материала;
- краткие сведения о последнем уроке.

Полный `learner/events.jsonl` не входит в snapshot. Команда сохраняет хэш текущих `profile.json`, `settings.json`, `mastery.json` и файлов уроков как baseline чата.

## Во время чата

Для получения данных только выбранных элементов использовать `python3 tools/kotoba_bionic.py items ID...`. Урок сохраняется только если он действительно проведён. Модель держит короткий список фактических результатов текущего чата и передаёт его в `finish`, не выполняя отдельную команду после каждого ответа.

## Конец чата

```bash
python3 tools/kotoba_bionic.py finish \
  --known ITEM_ID \
  --result ITEM_ID:SCORE:MODE \
  --lesson lessons/FILE.json
```

Все аргументы повторяемые и необязательные. `finish` валидирует урок, пакетно записывает известные элементы и оценки, обновляет `learner/context.json` и добавляет одно событие `chat_checkpoint`. Без изменений checkpoint пропускается. Если предыдущий чат оборвался, следующий `begin` обнаружит изменение хэша и восстановит checkpoint с причиной `recovered-at-start`.

`learner/context.json` — производный кэш, а не новый источник истины. Его можно восстановить из канонических файлов в любой момент.
