# Дополнительные источники

Проект должен работать полностью офлайн. Внешние репозитории, словари и MCP рассматриваются как опциональные источники, а не обязательная часть курса.

Перед подключением источника проверить:

1. лицензию на данные и возможность производных материалов;
2. наличие японского написания, чтения и значения;
3. стабильные идентификаторы или возможность их сопоставить с Kotoba ID;
4. качество примеров и отсутствие автоматически сгенерированных ошибок;
5. возможность локального использования без сети.

Локальный источник описывать в `sources/manifest.json`:

```json
{
  "sources": [
    {
      "name": "example-dictionary",
      "type": "local-repository",
      "path": "/absolute/path/to/repository",
      "license": "LICENSE-ID",
      "enabled": false
    }
  ]
}
```

Не копировать учебные тексты или словари в каталог проекта без совместимой лицензии. MCP с сетью должен быть явно включён пользователем; отсутствие MCP не должно ломать урок.
